# 答辩演示脚本（3 分钟）

> 目标：让评委在 3 分钟内看到"五件事都跑通"，并且知道代码是怎么分层的。

## 0. 准备（演示前 1 分钟）

```powershell
cd C:\Users\12966\Documents\华清远见\大模型考试\voice_assistant
run.bat
```

> 大模型 Key 已经从系统环境变量自动读取，不用再填；左下角显示"准备就绪"、左侧「模型」显示
> `DeepSeek · deepseek-chat` 就说明接的是真模型（如果是"离线演示模型 · mock"说明 Key 没读到）。

检查左下角：`准备就绪：喊一声「小清」试试`；左侧「识别 / 播报 / 模型 / 麦克风」四行都正常。

## 1. 唤醒 + 听写（40 秒）

- 对着麦克风说：**"小清"**
- 状态胶囊 待唤醒 → **聆听**（绿色），波形开始动
- 再说：**"今天北京天气怎么样"**
- 状态变成 **思考**（黄色，出现"正在思考…"占位），然后 **说话**（紫色），最后回到 待唤醒
- 指一下气泡：用户消息右上角标着"语音识别"，说明这句话来自麦克风而不是打字

**要讲的点**：Vosk 本地模型离线识别；唤醒=识别文本里匹配名字；别名 + 模糊匹配解决"小清/小晴/小琴"听岔的问题。

## 2. 大模型 + 记忆（50 秒）

- 打字（或说）：**"我叫阿伟"**
- 再说：**"你还记得我叫什么吗"** → 回答里出现"阿伟"
- 指左侧「对话记忆」：显示 `2 / 3 轮`，说明只保留最近 3 轮

**要讲的点**：`ConversationMemory` 用定长队列；每轮请求都是 `system + 最近 3 轮 + 当前问题`；超过 3 轮自动挤掉最早的。

## 3. 工具调用（50 秒）

- 说/打：**"帮我算一下 128 乘以 7"** → 气泡下方出现黄色工具标签 `工具 · calculate(...) → 896`
- 说：**"现在几点了"** → `get_current_time`
- 说：**"今天上海天气怎么样"** → `get_weather`

**要讲的点**：模型自己决定调不调工具（function calling），Agent 拿到 tool_calls 后真正执行，再把结果回填给模型，最多 3 轮防死循环；工具轨迹在界面上可见。

## 4. 语音朗读 + 界面（20 秒）

- 回答时状态是 **说话**，能从音箱听到 Edge-TTS 的神经语音
- 朗读期间麦克风数据会被丢弃（防回声）
- 每条气泡右上角的 **🔊 喇叭**可以单独重读这句话，朗读时变成 ⏹，再点就停
- 底部「说话」按钮不会被朗读"接管"，朗读中它仍是「🎤 说话」；点一下会打断朗读并开始听你说
- 点「说话」开始听、再点「停止聆听」结束；如果一直没出声，会自动回到「待唤醒」并提示"没听到声音"

## 5. 加分项演示（20 秒）

- 打开「设置」→ 把唤醒词改成 **"小明"** → 保存（服务自动重启）→ 喊"小明"也能唤醒
- 或者：改成"小助手"，把别名填几个谐音；说明唤醒词完全可配置
- 让评委看 `tools/smoke_test.py` 的输出：25 项自检全绿（识别/记忆/工具/Agent/VAD/TTS）

## 6. 一张图讲清代码结构

```
界面 (PySide6)  ←信号—  AssistantWorker(QThread) 状态机
                              ├─ audio.py    采集 + 能量 VAD
                              ├─ wakeword.py 唤醒匹配
                              ├─ asr.py      Vosk 识别
                              ├─ agent.py    记忆 + 模型 + 工具循环
                              ├─ tts.py      Edge-TTS / SAPI
                              └─ tools.py    天气 / 时间 / 计算器
```

**收尾话术**：每一层都是"接口 + 多个实现 + 工厂降级"，所以换识别模型、换大模型、换音色都不动主流程；
没有麦克风、没有 Key、没有网络时也不会崩，只在界面上说清楚降级到了哪个后端。
